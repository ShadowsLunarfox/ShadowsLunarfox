# Comic Neue

Comic Neue is a cartoon handwriting font by the Comic Neue Project Authors.
It is distributed under the SIL Open Font License 1.1; see [OFL.txt](OFL.txt).
The license permits free personal and commercial use and embedding, with the
copyright notice and license retained. It is an open-source font, not public domain.

Sources:

- [Official font project](https://github.com/crozynski/comicneue)
- [Google Fonts source and license](https://github.com/google/fonts/tree/main/ofl/comicneue)
- [Regular WOFF2](https://fonts.gstatic.com/s/comicneue/v9/4UaHrEJDsxBrF37olUeD96rp5w.woff2)
- [Bold WOFF2](https://fonts.gstatic.com/s/comicneue/v9/4UaErEJDsxBrF37olUeD_xHM8pxULg.woff2)

The Latin webfont files are kept locally and embedded as data URLs in generated
SVGs by `.github/scripts/profile-font.cjs`. Every resulting SVG also includes the
full OFL notice in its metadata. Rendering needs no installed font or font service.
